Privacy Policy for Tab-it

Effective date: September 13, 2026

Tab-it is a Chrome extension that replaces the New Tab page with a tab-management workspace. It lets users organize open and saved tabs into workspaces and collections.

Information handled by Tab-it

To provide its tab-management features, Tab-it may access and process:

  • Tab metadata from the current browser window, including page title, URL, favicon URL, tab identifier, and active state.
  • Saved tab metadata that the user chooses to organize in Tab-it.
  • User-created workspaces and collections.
  • Extension settings such as theme and preferred view.
  • Local feature counters such as the number of tabs opened or saved and the number of workspaces or collections created.

How information is used

This information is used only to provide Tab-it's core functionality: displaying current tabs, saving and organizing tabs, reopening tabs, closing tabs at the user's request, preserving workspaces and collections, and remembering extension settings.

Where information is stored

Tab-it stores its data locally on the user's device using Chrome's chrome.storage.local API. Tab-it does not provide user accounts, cloud synchronization, advertising, or a developer-operated analytics backend.

Network requests and favicons

When Chrome provides a website favicon URL for a tab, the extension may display that favicon. Loading that image can result in a normal request to the website or image host that provides the favicon. Tab-it does not send tab data to a developer-operated server.

Sharing and sale of data

Tab-it does not sell user data. Tab-it does not share user data with advertisers or data brokers, and it does not use browsing activity for advertising, credit-worthiness, or lending purposes.

Chrome permissions

  • tabs: used to read current tab metadata and perform user-requested tab actions such as opening and closing tabs.
  • storage: used to save workspaces, collections, saved tab metadata, settings, and local counters on the user's device.

Data retention and deletion

Data remains in Chrome local extension storage until the user removes it through the extension (where available), clears extension data, or uninstalls Tab-it. Uninstalling the extension removes its local extension storage.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If Tab-it's data practices change, this Privacy Policy will be updated before or at the same time as those changes are released.
